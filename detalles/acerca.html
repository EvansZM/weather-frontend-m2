Sobre Aurora 🌦️

Una aplicación simple y visual para consultar el clima en distintas ciudades de Chile.

Sobre el proyecto

Aurora es un proyecto académico desarrollado con HTML, CSS, Bootstrap y JavaScript. Su objetivo es mostrar información climática de forma clara, ordenada y fácil de usar.

Este proyecto busca reforzar conceptos como estructura semántica, navegación entre páginas y diseño responsive.

Tecnologías utilizadas

HTML5

Estructura semántica del sitio.

CSS3

Estilos personalizados.

Bootstrap

Diseño responsive y componentes.

JavaScript

Navegación entre páginas.

Objetivo

Ofrecer una experiencia simple para consultar el clima y practicar los fundamentos del desarrollo frontend.
